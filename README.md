# VAnimation

**Shared animation orchestration by Vack Studio.** VAnimation lets Minecraft plugins request predefined visual effects through a consumer-bound API, with bounded timelines, cancellation and owned-resource cleanup. Games retain ownership of their rules, movement and rewards.

## Features

- Consumer-scoped handles, completion outcomes and cancellation.
- Shared timeline scheduling, priority queues and configurable resource limits.
- Six vanilla effect definitions and six particle shapes.
- Item, block and text display animation with transforms and per-viewer visibility.
- English by default, selectable Arabic, UUID-based language preferences and administrative diagnostics.

## Requirements and verification

Targets **Paper 26.2 and Java 25**. The current version is **0.1.0-preview.1**. The build passed 35 unit tests and 18 isolated server checks on Paper 26.2 build 134. No players connected during that server probe; graphical rendering and real multiplayer behavior still require acceptance testing.

Pack, audio and menu adapters remain deferred pending their verified identity, ownership and readiness contracts. No Folia, Leaf, Bedrock or proxy compatibility claim is made.
